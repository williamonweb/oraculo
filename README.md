# Oráculo Tarot

Aplicativo web responsivo de tiragem simbólica de tarot em português.

## O que já funciona

- Tiragem de uma carta ou de três cartas.
- 22 Arcanos Maiores, cada um com ilustração original, leitura normal e invertida.
- Animação de embaralhamento e revelação.
- Interpretação, conselho e pergunta para reflexão.
- Sons suaves que podem ser desligados.
- Compartilhamento da leitura.
- Histórico salvo localmente no aparelho.
- Instalação como aplicativo (PWA) quando publicado em HTTPS.
- Uso offline após o primeiro acesso.

## Executar localmente

Abra um terminal nesta pasta e rode:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080` no navegador.

O tarot do aplicativo é apresentado como ferramenta simbólica de reflexão e não substitui orientação médica, jurídica, financeira ou psicológica.
